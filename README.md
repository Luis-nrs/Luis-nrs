### Micra-Core

A complete in-car system for a 2009 Nissan Micra K12 that never had one.

| Part | What it does |
|---|---|
| ESP32-C6 + CAN transceiver | Listens to the car's bus: speed, RPM, gear, throttle, brakes, ABS, fuel, doors, lights |
| Raspberry Pi 5 | Dashcam with crash buffer, sentry mode, trip log, fuel book, self-healing services |
| Cluster UI | Full-screen digital gauge with shift hints, G-meter and steering estimate |
| Power | Portable power station controlled over Bluetooth, everything updatable over the air |

Decoded CAN IDs are public: **[nissan-micra-k12-can-ids](https://github.com/Luis-nrs/nissan-micra-k12-can-ids)**
